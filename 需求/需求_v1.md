# Windows 全局剪切板管理器 —— 需求文档 v1

> **项目代号**: ClipBoardX  
> **创建日期**: 2025-01  
> **版本**: v1.0  

---

## 1. 项目背景

### 1.1 现状痛点

| 对比项 | Windows 默认剪切板 | 手机输入法剪切板（如搜狗/百度/讯飞） |
|--------|-------------------|-----------------------------------|
| 历史记录 | ❌ 仅保存最近 1 条 | ✅ 保存全部记录（不删除则永久保留） |
| 记录浏览 | ❌ 不支持 | ✅ 弹出列表，可上下翻页浏览 |
| 按需选择 | ❌ 不支持 | ✅ 点击任意条目即可粘贴 |
| 驻留方式 | 系统级（无 UI） | 输入法面板内常驻 |
| 分类管理 | ❌ 不支持 | ✅ 支持收藏/标记/分类 |

用户在日常 Windows 办公中频繁进行复制粘贴操作，但默认剪切板只能保留最近一次复制的内容，一旦复制新内容，旧内容即被覆盖丢失，严重降低工作效率。

### 1.2 目标

在 Windows 操作系统上实现一套**类手机输入法剪切板**的桌面端剪切板管理器，满足以下核心诉求：

- 自动监听并保存所有复制/剪切操作的历史记录
- 提供全局快捷唤起的剪切板面板（类似手机输入法的弹出列表）
- 支持在历史记录中浏览、搜索、选中并粘贴
- 记录持久化保存（不删除则永久保留）
- 轻量、无侵入、低资源占用

## 2. 功能需求

### 2.1 核心功能（P0 - 必须实现）

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F-01 | 剪切板历史记录自动捕获 | 监听系统 Clipboard 变化，自动保存每次复制/剪切的内容 | P0 |

| F-05 | 记录删除 | 支持单条删除 / 清空全部历史 | P0 |
| F-06 | 系统托盘驻留 | 程序启动后在系统托盘中运行，右键菜单可退出/设置 | P0 |

## 4. 项目结构设计

### 4.1 技术选型建议

| 层级 | 技术方案 | 说明 |
|------|---------|------|
| 编程语言 | **Rust** 或 **C# (WPF)** | Rust 性能好、体积小；C# WPF 开发效率高、Windows 生态好 |
| UI 框架 | **Rust: egui / Tauri**；**C#: WPF / WinUI 3** | 面板 UI 需要支持全局弹出、半透明、焦点穿透等特性 |
| 剪切板监听 | **Rust: clipboard-win + win32 API**；**C#: System.Windows.Clipboard + Win32 API** | 需通过 Windows 消息循环监听 WM_CLIPBOARDUPDATE |
| 数据存储 | **SQLite**（通过 rusqlite 或 Microsoft.Data.Sqlite） | 轻量、零配置、嵌入式 |
| 全局热键 | **Rust: global-hotkey**；**C#: RegisterHotKey Win32 API** | 注册系统级快捷键 |
| 构建工具 | **Rust: cargo**；**C#: MSBuild / dotnet build** | - |

> **推荐方案**: Rust + egui + SQLite + tray-icon，打包为单个可执行文件，体积小、免安装。

## 5. 交互流程

### 5.1 用户操作流程

```
用户操作                 系统响应
─────────               ─────────
1. 用户复制文本 (Ctrl+C)  → 系统剪切板更新
                         → 监听器捕获变更
                         → 提取内容 → 写入 SQLite
                         → 更新面板列表

2. 用户按下全局热键       → 剪切板面板弹出
                         (置顶、半透明、带焦点)
                         → 从数据库加载历史记录
                         → 按时间倒序渲染列表

3. 用户浏览/搜索          → 实时过滤列表

4a. 用户点击某条记录      → 将该记录写入系统剪切板
                         → (可选) 自动模拟 Ctrl+V 粘贴
                         → 面板自动隐藏

4b. 用户删除某条记录      → 从数据库删除
                         → 列表实时更新

5. 用户再次按热键/ESC    → 面板隐藏
```

```
应用程序启动
    │
    ▼
读取配置（热键、主题、最大条数等）
    │
    ▼

    │
    ▼
注册全局热键 & 系统托盘图标
    │
    ▼
启动剪切板监听循环（窗口消息循环）
    │
    ▼
┌─────────────────────────────────────────┐
│  等待事件：                              │
│  ├─ 剪切板变更 → 保存记录               │
│  ├─ 热键触发   → 显示/隐藏面板          │
│  ├─ 托盘菜单   → 设置/关于/退出         │
│  └─ 退出信号   → 资源清理 → 退出        │
└─────────────────────────────────────────┘
```

## 6. 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Windows 剪切板 API 限制 | 某些应用使用自定义剪切板格式，可能无法捕获 | 回退到定时轮询 + 支持多种格式 |
| 全局热键冲突 | 与其他软件热键冲突导致功能失效 | 提供可自定义热键 + 热键冲突检测 |
| 面板焦点管理 | 面板弹出后需要"穿透"焦点到后台窗口实现自动粘贴 | 使用 WS_EX_LAYERED + 低完整性级别窗口 |
| 隐私顾虑 | 用户可能不希望某些敏感内容被记录 | 提供"忽略窗口"白名单 + 一键清空 + 本地存储不上传 |
| 高频率复制导致性能问题 | 连续快速复制可能触发大量数据库写入 | 防抖去重（500ms 内相同内容只存一次）+ 异步写入 |
